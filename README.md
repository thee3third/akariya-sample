# 炭火とビール 灯り屋 — 制作サンプル

山梨HPかけこみ寺の営業用**制作サンプル**（架空の居酒屋ホームページ）です。
営業時に「居酒屋ならこんな感じになります」とお見せするためのもので、実案件と同じ品質基準で作っています。

- 業態：炭火焼き × 山梨クラフトビールの大衆居酒屋（架空）
- 技術：**素のHTML / CSS / JS のみ**（ビルドツール・フレームワーク不使用 ＝ 納品後の保守最優先）
- 構成：5ページ＋404、モバイルファースト、ダークトーン

> ⚠️ 店名・住所・電話番号・価格はすべて**サンプル用の架空**です。フッターに制作サンプルである旨の注記を必ず表示しています。

## ローカルでの確認方法

素のHTMLなので、**`index.html` をブラウザで開くだけ**でほぼ確認できます。

ただし、`fetch` 等は使っていないものの、相対パス・iframe・フォント読み込みを実環境に近い形で確認したい場合は、簡易サーバ経由を推奨します。

### A. ただ開く（最速）
`index.html` をダブルクリック、またはブラウザにドラッグ＆ドロップ。

### B. 簡易サーバで開く（推奨）

Python がある場合（プリインストール多し）：

```bash
# このフォルダ直下で
python -m http.server 8000
# → ブラウザで http://localhost:8000/ を開く
```

Node がある場合：

```bash
npx serve .
# 表示された http://localhost:3000 等を開く
```

VS Code なら拡張機能 **Live Server** の「Go Live」でも可。

### レスポンシブの確認
ブラウザの開発者ツール（F12）→ デバイスツールバーで **375px / 768px / 1200px** を切り替え。
スマホ幅（〜767px）でのみ、画面下の固定バー（電話する／地図を見る）とハンバーガーメニューが表示されます。

## GitHub Pages での公開手順

相対パス構成なので、リポジトリ直下に置けばそのまま公開できます。

1. GitHub で新規リポジトリを作成（例：`akariya-sample`）。
2. このフォルダの中身を**リポジトリ直下**にコミット＆プッシュ。
   ```bash
   git init
   git add .
   git commit -m "炭火とビール 灯り屋 サンプルサイト"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
3. リポジトリの **Settings → Pages** を開く。
4. **Build and deployment → Source** を「Deploy from a branch」、**Branch** を `main` / `/(root)` に設定して保存。
5. 数十秒〜数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

### 公開時の注意
- **404.html**：GitHub Pages は存在しないURLで自動的に `404.html` を返します（追加設定不要）。
- **日本語ファイル名**：`撮影リスト.md` はドキュメントのため公開に影響しませんが、気になる場合は `SHOOTING-LIST.md` 等にリネーム可。
- **ユーザーサイト（`<ユーザー名>.github.io` リポジトリ）として公開**する場合はサブパスが付かないため、相対パスのまま完全に動作します。プロジェクトサイト（サブパスあり）でも相対パス構成のため動作します。

## 公開前セルフチェック（実施済み）

このサンプルは以下を確認済みです。差し替え後の実案件でも同じ手順でチェックしてください。

- ✅ 内部リンク切れなし（全ページ間のナビ・フッター）
- ✅ アセット（CSS/JS/favicon）参照切れなし
- ✅ `tel:` リンク（`tel:055-000-0000`）が全ページで機能
- ✅ 全ページに title（「ページ名｜炭火とビール 灯り屋」形式）/ description / OGP / favicon / viewport
- ✅ フッターの制作サンプル注記が全6ページに存在
- ✅ `target="_blank"` に `rel="noopener"` 付与漏れなし
- ✅ レスポンシブ 375 / 768 / 1200px で表示崩れなし（実ブラウザでスクリーンショット目視確認）
- ✅ 固定電話バーがスマホ（〜767px）でのみ表示・PCで非表示

### チェックに使えるコマンド（Git Bash 等）
```bash
# tel:リンクの本数
grep -c 'href="tel:' *.html
# 外部リンクの noopener 漏れ
grep -n 'target="_blank"' *.html | grep -v noopener
# 制作サンプル注記の有無（実案件では 0 にする）
grep -l "山梨HPかけこみ寺" *.html
```
